##📌 Key Concepts
Exception is an event that interrupts the normal execution of a program.
Checked Exceptions are verified by the compiler and must be handled using try-catch or throws.
Unchecked Exceptions occur at runtime and are usually caused by programming errors.
Errors represent serious system-level problems that applications generally cannot recover from.
The finally block is mainly used for resource cleanup and executes whether an exception occurs or not.
