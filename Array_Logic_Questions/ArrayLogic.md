# Java Arrays Practice

This repository contains Java programs that demonstrate fundamental array operations, including array traversal, filtering elements, and finding the maximum element.

## 📚 Programs Covered

### 1️⃣ Print Array Elements Using For-Each Loop

* Created an integer array.
* Traversed the array using the enhanced **for-each loop**.
* Printed all array elements.

**Concepts:**

* Arrays
* For-Each Loop
* Array Traversal

---

### 2️⃣ Print Even Numbers from an Array

* Accepted the array size from the user.
* Inserted array elements into the array.
* Traversed the array.
* Printed only the even numbers.

**Concepts:**

* Scanner Class
* Arrays
* For Loop
* Conditional Statements (`if`)
* Modulus Operator (`%`)
* Array Traversal

---

### 3️⃣ Find the Maximum Element in an Array

* Accepted the array size and elements from the user.
* Assumed the first element as the maximum.
* Compared each element with the current maximum.
* Displayed the largest element in the array.

**Concepts:**

* Arrays
* Scanner Class
* For Loop
* Comparison Operators
* Linear Search

---

## 🎯 Key Learnings

* Creating arrays dynamically using user input.
* Traversing arrays using both `for` and `for-each` loops.
* Filtering array elements with conditional statements.
* Finding the maximum element using linear search.
* Understanding the time and space complexity of array operations.
