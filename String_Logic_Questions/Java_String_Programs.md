# 📚 Java String Programs

This repository contains basic **Java String Programs** that are commonly asked in interviews and university practical exams. These programs help in understanding string manipulation, character processing, loops, and conditional statements without relying heavily on built-in library methods.

---

## 📋 Programs Included

### 1. Search String in an Array
**Description:**
Searches for a given string in a string array and displays whether it is found or not.

**Concepts Used:**
- String Array
- Loop
- `equals()` / `equalsIgnoreCase()`
- Boolean Flag

---

### 2. Reverse a String
**Description:**
Reverses the entire string by traversing it from the last character to the first.

**Concepts Used:**
- String
- Loop
- `charAt()`

---

### 3. Reverse the Order of Words
**Description:**
Reverses the order of words in a sentence.

**Example**
```
Input : Java is easy
Output: easy is Java
```

**Concepts Used:**
- String
- Arrays
- Loops

---

### 4. Reverse Each Word
**Description:**
Reverses each word individually while maintaining the original word order.

**Example**
```
Input : Java is easy
Output: avaJ si ysae
```

**Concepts Used:**
- String Traversal
- Nested Loops
- Character Manipulation

---

### 5. Concatenate Two Strings (Without Library Methods)
**Description:**
Concatenates two strings manually without using `concat()` or `StringBuilder`.

**Concepts Used:**
- Character Array
- Loops
- String Manipulation

---

### 6. Capitalize the First Letter of Each Word
**Description:**
Converts the first letter of every word into uppercase without using `toUpperCase()`.

**Example**
```
Input : java programming language
Output: Java Programming Language
```

**Concepts Used:**
- ASCII Values
- Character Manipulation
- Boolean Flag

---

### 7. Check Whether a String is Palindrome
**Description:**
Checks whether the given string reads the same forward and backward.

**Example**
```
Input : madam
Output: Palindrome
```

**Concepts Used:**
- String Reversal
- `equals()`
- Loops

---

### 8. Frequency of Each Character
**Description:**
Counts the frequency of every character present in the string.

**Example**
```
Input : programming

Output:
p = 1
r = 2
o = 1
g = 2
a = 1
m = 2
i = 1
n = 1
```

**Concepts Used:**
- Nested Loops
- Boolean Array
- Character Comparison

---

### 9. Remove Occurrences of a Specified Character
**Description:**
Removes all occurrences of a specified character from a string.

**Example**
```
Input :
programming
g

Output:
prorammin
```

**Concepts Used:**
- Character Comparison
- String Traversal
- Conditional Statements

## ▶️ How to Run

1. Clone the repository.
2. Open the project in any Java IDE (VS Code, IntelliJ IDEA, Eclipse, NetBeans).
3. Compile the program:
   ```bash
   javac FileName.java
   ```
4. Run the program:
   ```bash
   java FileName
   ```
